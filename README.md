# Personalized Fragrance Recommendation for Aromatherapy

This is the official repository for the research project titled  
**_"Personalized Fragrance Recommendation for Aromatherapy: A Machine Learning Approach Based on Personality Traits and Electrodermal Activity"._**

![Graphical Abstract](Graphical_Abstract.png)
## 📁 Dataset Overview

- `feature.csv`: This file contains the preprocessed dataset used in our study. It includes extracted features derived from personality trait assessments and electrodermal activity (EDA) signals, which were used for personalized fragrance recommendation modeling.
